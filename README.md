# Mat Coalson

Building energy engineer exploring the useful, demanding edge of AI: where systems need to be testable, understandable, and accountable to the people who use them.

I make tools and write about:

- **AI for engineering workflows** — evaluation harnesses, careful automation, and practical tools for technical work.
- **Local-first AI** — systems that preserve agency, privacy boundaries, and human judgment.
- **Story tools and writing** — experiments in character voice, narrative structure, and what it means to build with intelligent tools.

## A few places to start

- [mbcoalson.com](https://mbcoalson.com) — essays, tools, and ongoing projects
- [AI Engineering Toolkit](https://github.com/mbcoalson/ai-engineering-toolkit) — evaluation patterns for AI-assisted engineering work
- [Motifai](https://github.com/mbcoalson/motifai) — a work-in-progress voice-validation tool for fiction
- [Athena](https://github.com/mbcoalson/athena) — notes on my ongoing personal AI assistant project

Most of these projects are works in progress. I’d rather show the workshop honestly than pretend it is a showroom.
